Test Guide

Recommended first test

1. Activate a valid Nexus licence in Payment / Licence.

2. Keep Execution Mode on Paper Trading. No Binance key is needed.

3. Save settings, return to Overview, and start the engine.

4. Review one-minute scans, position updates, stop loss and take profit in the logs.

5. Only after paper checks pass, create Binance Futures Testnet keys and switch to Testnet.

Important boundaries

⚠ The local browser engine remains Paper/Testnet only. Version 5.1.0 mainnet execution is server-side, licence-authenticated, and isolated per customer.

⚠ The 24/7 engine combines deterministic technical rules with Gemini Search-grounded research as a risk veto and extreme-news exit. Neither layer guarantees returns or a 90% win rate.

⚠ Closing the browser does not stop your 24/7 account. If a managed position is open, use CLOSE LIVE POSITION; when flat, disable the engine before maintenance.

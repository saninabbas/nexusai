Test Guide

Recommended first test

1. Activate a valid Nexus licence in Payment / Licence.

2. Keep Execution Mode on Paper Trading. No Binance key is needed.

3. Save settings, return to Overview, and start the engine.

4. Review one-minute scans, position updates, stop loss and take profit in the logs.

5. Only after paper checks pass, create Binance Futures Testnet keys and switch to Testnet.

Important boundaries

⚠ Mainnet order execution is disabled in version 3.1.0.

⚠ The strategy engine uses deterministic RSI, EMA, MACD and breakout rules. It does not guarantee returns.

⚠ The extension must remain enabled for scheduled scans. Closing the dashboard does not stop the background engine.
